## 一、每数据集 prompt 复刻原论文(全新可插拔体系)

> 协议负责「通用怎么问」,本体系负责「按原论文逐字复刻怎么问」,两者解耦、缺省回退,互不影响。

### 新增
- **约定式 prompt 钩子**:新增 `src/evaluation/prompt_loaders.py`,按约定加载 `tasks/<数据集>/prompt.py`(仿照 metrics 的 `load_task_metric_fn` 范式)。数据集可选地覆盖三个钩子,任一缺省都回退通用实现:
  - `build_prompt(sample, option_map, include_instruction)`:user 侧 body 排版(story / question / options 措辞),签名与通用 `prompts.build_prompt` 完全一致。
  - `build_system_prompt(sample, protocol, lang, prompt_type)`:复刻官方 system prompt 的「注意事项」,仅把答案格式换成本框架的 `\boxed{}`。
  - `prepare_samples(samples)`:预测前对样本整体变换(打包子问题、设 `meta.prompt_type_override`)。
- **内置数据集全部接入**(BigToM / EmoBench / FanToM / HiToM / SocialIQA / TactfulToM / ToMBench 均有 `prompt.py`),代表性几套:
  - **ToMBench**:复刻 `[Story] / [Question] / [Candidate Answers]` 排版与官方 direct / cot system prompt(中英双语),保留「必须从选项中选一个、信息不足也随机选」的硬约束。
  - **FanToM**:复刻固定测试头 + 默认 `short_context`,Answerability 题前缀 `Target:`、Info-Accessibility 题前缀 `Information:`(所需字段由 `scripts/convert_fantom.py` 补进 `meta`)。
  - **EmoBench**:唯一额外定义 `prepare_samples`,把 EU 子集「情绪 + 原因」两问合并为一条 grouped 多问样本(EA 子集仍单问)。
- **新增 `mcq_grouped` 题型**:一个 prompt 内含多道子问题,`rule_judge_grouped` 抽取全文 `\boxed{}` 字母、取末尾 N 个对应各子问题,**每个子问题各对才算整体对**,并回填 `sub_results` 供按子问题(如 emotion / cause)做诊断聚合。
- 各数据集 `config.yaml` 增加 `prompt_style:` 注释标记(纯文档,代码不读取,仅便于检索)。

### 修改
- 预测链路 `prediction.py`:预测前先跑 `prepare_samples`;按题型分批改用 `defaultdict`,新题型(如 `mcq_grouped`)无需改动编排即可自动分批;带 `meta.prompt_type_override` 的样本跳过 `build_option_bundle`(选项已由 `prepare_samples` 打包)。
- **system / user prompt 分工明确化**:system prompt 只承载答题风格 + 格式指令,user prompt 只承载题目内容(故事 / 问题 / 选项);数据集 `build_system_prompt` / `build_prompt` 各自覆盖对应一侧,分工不变。
- `\boxed{}` 抽取正则放宽,兼容 `\box{}` 与 `\boxed{}` 两种写法。

## 二、组级「全对」二级指标

### 新增
- **`group_all_correct`**(`src/evaluation/task_metrics.py`):按 `key_fn` 分组,组内 `required_members` 全部答对才算该组通过;只统计成员齐全的组,避免缺成员的组虚高 / 虚低。返回 `{rate, passed, total}`。落地三处:
  - **FanToM**:set 级 ALL —— 同一 snippet 内全部 ToM 题型答对才算该 set 通过(对齐官方头条指标 `groupby(set_id).all().mean()`),并输出 `set_all` 通过数 / 总数便于核对口径。
  - **TactfulToM**:`joint_comp_just` —— 同一对话(set_id)的 Comprehension 与 Justification 都答对才算「真正理解了善意谎言」(Happé 双题判定),该联合分无法从两个边际 accuracy 推回。
  - **EmoBench**:EU 子集走 grouped 联合判分(两问都对),并从 `sub_results` 聚合 emotion / cause 各自 accuracy 作诊断。

### 修改
- FanToM 指标重构:原先内联的 `_all_metric` 收敛为统一的 `group_all_correct`,口径与官方一致(标准化数据 belief 为多选形式,对应官方 `All`(MC belief),非需自由文本 belief 的 `All*`)。
